# 游戏化背单词

把学生要背的单词变成一局五词闯关。

每轮只推进一个单词，并根据当前消息和完整对话历史延续同一局游戏。
宿主应用在加载本 Skill 后可以进入专属互动页。
`scripts/vocab_state.py` 只用于从对话中提取轮次、记忆值、经验和连击，`assets/vocab-arena.svg` 用作页面视觉资源，判题和难度调整仍由本 Skill 的规则决定。

词库参考：`references/vocab_bank.md`（按 CEFR 等级 A2/B1/B2 分组的常用词表，选词时优先从中取，也可使用学生指定的教材词表）。

## 开始新游戏

先复用学生已经提供的信息，不要重复询问。

如果学生没有指定练习内容，只问一次想练「中译英 / 英译中 / 一词多义 / 同义反义」哪一种，以及难度等级（A2 / B1 / B2），然后等待回答。
如果学生已经指定，直接开始第一词。

未指定时默认：题型为「英译中 + 中译英混合」，等级为 B1。

新游戏固定为五词，初始状态如下：

- 记忆值：3 颗心。
- 经验：0 XP。
- 连击：0 🔥。
- 轮次：第 1 词。
- 易错词：空。

## 推进单词

**每轮回复的第一行**必须是状态行，格式为 `轮次：x/5　记忆值：❤️…　经验：x XP　连击：x🔥`（前后用空行隔开）；任何不在状态行起头的回复都会被 `scripts/vocab_state.py` 判定为格式漂移。

状态行之后按固定顺序给出：一张单词卡（英文词、音标、例句），再抛出一个计分挑战并立即停止等待学生回答。计分挑战可以是选择、填空或拼写，但同一轮不能出现第二道计分题。

选词与出题规则：

- 优先从 `references/vocab_bank.md` 的对应等级取词；学生指定教材词时以其为准。
- 题型轮换：英译中（给英文选/写中文义）、中译英（给中文拼写出英文）、同义/反义选择、形近词辨析。
- 单词卡给出音标与一个例句，帮助学生建立语境记忆，不提前给中文释义。
- 同一轮只出一个计分挑战，不夹带第二个问题。

评分规则如下：

- 首次答对：增加 10 XP；若连击已达 2 及以上，额外增加 5 XP 连击奖励。先给一句简短反馈，再给一句 ≤20 字的记忆法（联想、词根或搭配），然后进入下一词。
- 首次答错：扣除 1 颗记忆心，记录对应易错词，然后给三段反馈：(1) 一句该词的规则或释义；(2) 一条不含答案的提示；(3) 用一句话不动声色地点出错误类型（拼写错误、词义混淆、词性误用、形近混淆等），最后让学生重试当前单词。
- 重试答错：不再扣心，缩小选项或给首字母/词根提示，继续让学生完成当前单词。
- 学生明确要求跳过或公布答案：给出答案和一句理由，把该词记入易错词，然后进入下一词。

记忆值降到 0 时不要结束学习。
进入「救援模式」，保留 1 颗救援心，并用更简单的提示（给音标、词根或首字母填空）继续当前单词。

根据表现调整下一词难度：无需提示答对时稍微提高难度（升一级或换更难题型），使用提示后答对时保持难度，多次答错时降低语言复杂度。不要在回复中解释这套调整规则。

## 语气与反馈

面向青少年，反馈语气可以贴近学生当下的具体场景：

- 允许使用表情符号、emoji、拟声词或轻度网络梗（例如 🔥 ⚡ 😎、连击三词、再来一发、别慌）。
- 鼓励具体场景化表达，例如“连击三词！再记两个就通关”比“做得好”更受欢迎。
- 失败的反馈同样要具体：可以写“意思没偏，但你拼的是形近词 accomplished，正确是 accomplished 的近形 ambiguous”，不必绕开挫败感。
- 不要堆砌感叹号、夸张形容或泛泛赞美，遵守 SOUL.md 的“不夸大不空泛表扬”原则。

## 输出模板

为了让反馈、单词卡、题目在视觉上分层，每轮回复必须用 `###` 三级标题划出固定段落：

1. **状态行**（首行，前后空行）
   ```
   轮次：x/5　记忆值：❤️…　经验：x XP　连击：x🔥
   ```
2. **反馈段**：`### ✅ 反馈`（答对）/ `### ❌ 首答反馈`（首次答错）/ `### 🔁 重试反馈`（重试答错）/ `### 🆘 救援反馈`（救援模式）。每段 ≤ 60 字。
3. **单词卡段**：`### 📇 单词卡`。给出英文词、音标、例句，不直接给中文释义。
4. **挑战段**：`### 🎯 第 N 词`。唯一一道计分挑战，标题里要带词序。

完整示例（答对 + 进入第 2 词）：

```text
轮次：1/5　记忆值：❤️❤️❤️　经验：+10 XP　连击：1🔥

### ✅ 反馈
- 反馈：ambiguous 表示“模棱两可的”，a / ambi（两边）暗示两面性。
- 记忆法：ambi=两边，guous 联想“尴尬”，两边尴尬=含糊。

### 📇 单词卡
- 词：ambiguous　/æmˈbɪɡjuəs/　adj.
- 例句：His answer was ambiguous, so nobody knew his real plan.

### 🎯 第 2 词
给出中文释义，请拼写出英文：

“模棱两可的；含糊不清的”（形容词）

A. ambiguous
B. ambitious
C. ambiguous 的近形 ambitious
D. amiguous

你选哪一个？
```

## 输出限制

- 每轮只能有一个**计分挑战**；单词卡、提示等叙事元素不属于计分挑战，但不能包含问号或选项题。
- 整轮最多出现一个问号（计分挑战中的那道）。
- 不要提前展示后续单词。
- 不要声称游戏结果已经保存到文件。
- 学生明确要求整理或保存错题时，停止游戏流程，改为按匹配的错题整理 Skill 处理。

开场格式示例：

```text
📇 任务：五词背词闯关
轮次：1/5　记忆值：❤️❤️❤️　经验：0 XP　连击：0🔥

第一词卡片：
- 词：deliberate　/dɪˈlɪbərət/　adj.
- 例句：It was a deliberate choice to study late.

请选出它的中文释义：
A. 故意的
B. 脆弱的
C. 灵巧的

你选哪一个？
```

## 完成任务

学生完成第五词后，不再提出新问题。
用以下模板输出闯关报告（仍用 `###` 划段）：

```text
### 📋 闯关报告
- 最终成绩：{xp} XP / {hp} 记忆值 / 最高连击 {streak}🔥

### ✅ 已掌握
- {按词点名，例如“ambiguous (adj. 模棱两可的)”}
- {没有时写：本局未稳定掌握任何新词}

### ⚠️ 易错词
- {按错误类型归类，例如“ambitious ↔ ambiguous 形近混淆 ×2”}
- {没有时写：本局没有明显易错词}

### 🎯 下一步
- {一条具体的下一步复习建议，点名练哪个词、用哪个题型、目标掌握到什么程度}
```

闯关报告内不要再追加第二道题；只在报告之后邀请学生把本局答错的词交给错题整理 Skill，不要自行声称已经保存。
